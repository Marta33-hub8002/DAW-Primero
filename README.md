# DAW - Primero de Desarrollo de Aplicaciones Web

📚 Repositorio con ejercicios, prácticas y proyectos de Primero de DAW

## 📂 Estructura del Repositorio

```
├── 01-programacion/          # Ejercicios de Java
│   ├── java-basico/          # Conceptos básicos
│   ├── ejercicios-funciones/ # Métodos y funciones
│   ├── arrays-listas/        # ArrayList y estructuras de datos
│   └── ejercicios-variados/  # Ejercicios complementarios
├── 02-bases-de-datos/        # SQL y bases de datos
│   └── sql/                  # Consultas y DDL
├── 03-web/                   # HTML y CSS
│   ├── html/                 # Archivos HTML
│   └── css/                  # Estilos CSS
├── 04-entornos/              # Configuración de entornos
│   ├── idea/                 # Configuración de IntelliJ IDEA
│   └── configuracion/        # Archivos de configuración
└── 05-extra/                 # Recursos adicionales
    └── apuntes/              # Notas y apuntes
```

## 🎯 Contenido

### Programación Java
- Conceptos básicos (variables, operadores, tipos de datos)
- Estructuras de control (if/else, bucles)
- Funciones y métodos
- Arrays y ArrayList
- Ejercicios prácticos variados

### Bases de Datos
- Consultas SQL
- DDL (Data Definition Language)
- Operaciones CRUD

### Desarrollo Web
- Estructura HTML
- Estilos CSS
- Prácticas de maquetación

## 📝 Notas

- Los ejercicios están organizados por bloques temáticos
- Cada carpeta contiene archivos relacionados con el mismo tema
- Los archivos de configuración de IntelliJ IDEA se encuentran en `04-entornos/idea/`
